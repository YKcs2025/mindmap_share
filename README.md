# マインドマップ（スマホ・PC対応 / ローカル保存 / AI連携）

```
mindmap/
  mindmap.html          … エディタ本体（1ファイル完結）
  index.html            … mindmap.html へ転送するだけ（公開URL用）
  manifest.webmanifest  … ホーム画面に追加するための設定
  sw.js                 … オフラインでも開けるようにする仕組み
  icon-*.png            … アプリのアイコン
  server.py             … （任意）PCの maps/ にスマホから保存したいとき用
  maps/                 … データ置き場（1マップ＝1フォルダ）
    README.md           … 書式の説明（AIに読ませる用）
    index.md            … マップ一覧（自動生成）
    2026-10-10_テーマ/
      map.md            … AI向けの階層Markdown（自動生成）
      map.json          … 正本（位置・色・画像サイズ等すべて）
      images/           … 画像
```

## スマホだけで使う（Android / iPhone 共通の準備）

スマホではHTMLファイルを直接開けないので、**一度だけ** 無料の GitHub Pages にアプリ本体を置いてURLで開けるようにします。
置くのはアプリ本体だけで、**マップのデータはスマホの中に保存され、外には送られません。**

1. スマホのブラウザで https://github.com を開き、アカウントを作る（またはログイン）
2. 右上の「＋」→「New repository」→ 名前に `mindmap` → **Public** を選んで「Create repository」
3. 「uploading an existing file」をタップ → ZIPを展開した `mindmap` フォルダの中から、
   **`maps` フォルダ以外のファイルをすべて** 選んでアップロード →「Commit changes」
   （アップロードできない場合はブラウザのメニューで「PC版サイト」に切り替えてください）
4. リポジトリの「Settings」→ 左メニュー「Pages」→ Branch を `main`、フォルダを `/ (root)` にして「Save」
5. 1〜2分待って `https://<あなたのユーザー名>.github.io/mindmap/` を開く

### Android（Chrome）
- メニュー（︙）→「ホーム画面に追加」（または「アプリをインストール」）
- アプリを開いて一覧の **「フォルダに保存」** → スマホ内のフォルダ（例：`Documents` に `mindmap` フォルダを作って選ぶ）
- 以後、そのフォルダの `maps/` に map.md・map.json・画像が自動保存されます。ファイルアプリから見たり、AIアプリに添付したりできます
- 次回起動時に「再接続」ボタンが出たら、タップして許可するだけで戻れます

### iPhone（Safari）
- 共有ボタン →「ホーム画面に追加」→ ホーム画面のアイコンから開く
- iPhoneは仕組み上フォルダに直接書き込めないため、データはアプリ内に保存されます
- 「バックアップ」ボタンで ZIP を作り、共有シートの「"ファイル"に保存」で iCloud Drive などに残せます。展開すると上の `maps/` と同じ構成です
- 別の端末へ移すときは、そのZIPを「読み込み」で取り込みます
- ※ ホーム画面に追加せずSafariのタブで使うと、長期間開かなかったときにデータが消されることがあります

### アプリを更新したとき
GitHub上の `mindmap.html` を差し替えたら、`sw.js` の `VERSION` の数字も1つ上げてアップロードすると、各端末で新しい版に切り替わります。

## PCで使う
- `mindmap.html` をダブルクリック（Chrome / Edge）→「保存先」→ この `mindmap` フォルダを選ぶと `maps/` に直接保存
- 上の GitHub Pages のURLをPCで開いても同じように使えます
- （任意）PCの `maps/` にスマホから直接保存したいときは `python3 server.py` を実行し、表示されたURLを同じWi-Fiのスマホで開く

## 操作
- **スマホ**: タップで選択、ドラッグで移動、2本指でズーム、ダブルタップで編集、空白ダブルタップで独立ノード。下のバーから子・兄弟・画像・詳細・親を変更・関連線・削除
- **PC**: `Tab` 子 / `Enter` 兄弟 / `F2` か文字入力で編集 / `Delete` 削除 / `Space` 折りたたみ / 矢印キーで移動 / `Ctrl+Z` 元に戻す / ホイールでズーム / `Alt`+ドラッグで単独移動
- **画像**: 画像ボタン（スマホはカメラ・写真から）、`Ctrl+V`、ドラッグ＆ドロップ。選択中ノード右下の丸でサイズ変更
- **箇条書きの貼り付け**: ノードを選んで箇条書きを貼り付けると子ノードとして一括追加

## 人に共有する（相手が見る・編集する）

マップ右上の **共有ボタン** →「ファイルで共有」で、**1つのファイル（`マップ名.html`）** ができます。LINE・メール・AirDropなどでそのまま送れます。
このファイルには、エディタ本体・マップのデータ・画像・AI用Markdown・全体図がすべて入っています。

| 受け取った人 | できること |
|---|---|
| スマホ（iPhone / Android） | ファイルをタップすると、**全体図と内容（箇条書き・メモ）が表示**される。「このマップを編集する」ボタンでアプリが開き、編集できる |
| PC | ファイルをブラウザで開くと、**そのまま編集画面**になる |
| AI | このファイル（またはマップの map.md）を渡せば内容を読める |

- 編集した人は、同じく「共有」→「ファイルで共有」で送り返します
- 送り返されたファイルは、アプリの「読み込み」（または「⋯ → 受け取ったファイルを開く」）で取り込みます。同じマップなら **「上書きして更新」** か **「別のマップとして追加」** を選べます
- 「このマップを編集する」ボタンの行き先は、GitHub Pages などで公開したアプリのURLです。公開URLからアプリを使っていれば自動で入ります。PCのファイルから使う場合は、一覧の「⋯ → 共有ファイルに入れる編集用URL」で設定してください（未設定だと、スマホの相手は閲覧のみ）
- 画像なしのマップなら、ボタンを押すだけで相手のアプリにマップが入ります。画像ありのマップは、ボタンでアプリを開いてから「ファイルを選ぶ」でこのファイルを選びます
- 同じマップを複数人が同時に編集することはできません（ファイルを交互にやり取りする形です）
- サッと見せるだけなら「画像で共有」で全体図のPNGも作れます

## AIとの連携
1. 右上の ✦ ボタン → AI向けMarkdownがコピーされる（AndroidならフォルダのMarkdownファイルをそのまま渡してもOK）
2. AIに「この書式のまま、`<!-- id:… -->` は残して、追加・修正したものを返して」と頼む
3. 返ってきたMarkdownを「⋯ → AIの編集を取り込む」に貼る → 件数を確認して反映

IDが残っているノードは位置・色・画像がそのまま引き継がれ、新しいノードだけ近くに自動配置されます。
AIに一から作ってもらった箇条書きは、一覧の「読み込み → テキストを貼り付けて作成」で新しいマップになります。
